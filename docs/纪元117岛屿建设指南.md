# 纪元117 · 岛屿建设指南

> 本文回答“这座岛要建多少、要多少人、总督府放哪、怎么排”四个问题。
> 数据：vitablo 生产线计算器（补丁 3.0）+ anno117.tools 建筑／卡牌库；
> 建筑占地、劳动力、维护费取自建筑详情页，住宅容量取自住宅页。

---

## 一、从「每分钟产量」倒推建筑数

1. 定目标：每种成品每分钟要出多少（例：面包 30/分）。
2. 算生产力：`P = (100 + 筒仓100 + 鸽舍50 + 研究 + 卡牌 + 全局) × 输水道系数(1.5)`。
3. 算单栋产能：`有效周期 t = 基础周期 ÷ (P/100)`，`单栋每分钟 = 60 ÷ t`。
4. 算数量：`所需栋数 = 目标产量 ÷ 单栋每分钟`，**每段产线分别向上取整**。
5. 汇总：劳动力、占地、维护费按「单栋数值 × 栋数」累加。

> 因为各段产线吃到的加成不同，比例很少是整数。取整后上游会略有过剩，
> 可以关掉一两栋，或把余量外销——本指南统一按“全部开工”计算。

## 二、总督府怎么放

| 项目 | 数值 |
|---|---|
| 占地 | 9 × 11 格 |
| 影响半径 | 36 格 |
| 街道连接范围 | 40 格 |
| 维护费 | -50 第纳里/分（负值＝净收入） |
| 解锁 | 首个平民 / 首个商贾 / 75 陶工 |

放置原则：

1. **放住宅区的几何中心**，不要贴在工业区。半径 36 格几乎覆盖整岛，真正要卡的是“紧邻住宅 + 门口接主路”。
2. **主路直连**：总督府门前必须是主干道，街道连接范围 40 格意味着它离路网不能太远。
3. **别挨着负面效果建筑**：猪圈（健康 −2）、面包房／盐工（防火 −2）、制皂师（健康 −1）这类建筑的影响范围要和住宅隔开一条主路。
4. **留出扩建位**：总督府周围预留 3–4 格空位，后期放广场、市场、浴场、神庙。

### 4.4 占地与岛屿选择

| 项目 | 格数 |
|---|---|
| 生产建筑 | 1084 |
| 道路与空隙（约 +35%） | 379 |
| 住宅 | 576 |
| 总督府 | 99 |
| 仓库 + 码头 | 36 |
| **合计** | **2174** |

建议选可建面积 ≥ **2826 格** 的岛（约 54×54 的连续平地）。放不下时按顺序砍：
先减产量 → 把原料农场外包到邻岛 → 拆成“加工岛 + 农业岛”。

### 4.5 分区布局

1. **原料区**（农场／矿场／采集）：占比最大，优先占平地与资源点，连成片；
2. **加工区**（作坊／工厂）：紧贴仓库，尽量沿一条主路排开，方便卡牌加成覆盖；
3. **仓储 / 码头区**：卡在原料区与加工区之间，码头朝外海；
4. **居住 / 市政区**：总督府居中心，第一圈广场／市场／浴场，第二圈住宅，外围仓库。

道路：主路 2 格宽贯穿全岛，支路每两排建筑一条，避免死胡同（运输车会绕路）。

## 五、常见坑

- **别按整数比硬套**：满科技下每段产线的加成不同，比例会跑偏，按“每分钟产量”算才准。
- **劳动力是硬约束**：先算工人再定住宅，住宅又带来新的需求，形成循环；建议先建生产、再补住宅、最后补住宅需求产线。
- **燃煤建筑单独配**：煤耗固定 0.5 吨/分，1 座炭窑养 4 栋，与周期无关。
- **不要把所有建筑塞进总督府半径**：半径 36 格基本覆盖全岛，真正影响体验的是道路连通与污染隔离。
- **卡牌不是越多越好**：每栋 3 槽，优先给“栋数最多”的建筑（通常是上游农场），收益最大。
