## 一、计算模型（所有配比的来源）

### 1. 生产力公式

```
生产力 P = ( 100 + 筒仓100 + 鸽舍50 + 研究加成 + 专家卡加成 + 额外加成 ) × 输水道系数
(接通蓄水池/输水道时系数 = 1.5，否则 = 1)
```

- **输水道是乘法**：基础生产变为 150%，因此会把其他加成一并放大。
- **筒仓 / 鸽舍 / 研究 / 专家卡 / 宗教是加法**：直接叠加在百分比上。

### 1.5 专家 / 物品卡

- 每栋生产建筑有 **3 个卡槽**，同一张卡不可重复；卡的加成与设施加成同为加法，先全部相加再乘输水道系数。
- 同名卡有**普通**与**传说**两个数值档（如胡伊 +35% / +50%），满级传说才是顶级数值。
- 卡是**按建筑生效**的：卡片标注影响哪类建筑（如「麦田 +35%」只作用于麦田），插错建筑无效。各建筑可选卡清单见下方每条产线的「推荐卡牌」。
- 例：麦田在「研究+10」且接通输水道时，P = (100+10)×1.5 = 165%，周期 60 秒 → 36 秒。
- 全部 **539 张**专家 / 物品卡（含住宅、航海、军事、市政类）的名称、效果（普通 / 强化两档）、强化条件与获取方式，见同目录 **《纪元117卡牌图鉴.md》**；网页版「卡牌图鉴」可按建筑类型筛选，「我的卡牌清单」用来记录收集进度。

### 2. 配比公式

```
有效周期 t_eff = 基础加工时间 ÷ (P / 100)
建筑数量 n_i = t_eff_i ÷ t_eff(成品建筑) × 目标数量
```

因为每栋建筑**每个周期消耗 1 吨输入、产出 1 吨产品**，所以建筑数量正比于有效周期——这就是所有「1:2」「4:3」配比的数学来源。

### 3. 燃料（煤）

```
每栋燃煤建筑 = 1 吨煤 / 2 分钟 = 0.5 吨/分（与自身周期无关）
1 座煤矿 / 炭窑（0:30，2 吨/分）→ 供养 4 栋燃煤建筑
```

拉丁姆本身没有煤矿，需从埃及（煤矿）或阿尔比恩用贸易线输入，或在本岛建炭窑。

### 4. 三种情景定义

| 情景 | 含义 | 适合 |
| --- | --- | --- |
| 无加成 | 全部 100%，不接任何设施 | 开局规划、对照攻略 |
| 满设施 | 该建筑可用时接满输水道/筒仓/鸽舍 | 中期 |
| 满科技 | 满设施 + 该建筑关联的全部研究加成 | 后期 |

> 宗教（守护神）不计入「满科技」：单一守护神只能覆盖部分建筑，无法全产线同时拉满。需要时按该建筑宗教上限（多为 +150%）自行叠加。专家卡由玩家自选，按「推荐卡牌」清单叠加。

## 三、常见问题

**Q：为什么面包链是 3:1:3，而有些攻略写 2:1:2？**
A：3.0 版谷物磨坊周期为 0:20（3 吨/分），麦田与面包房均为 1:00（1 吨/分），所以精确配比是 3 麦田 : 1 磨坊 : 3 面包房。旧攻略的 2:1:2 对应磨坊 0:30 的旧数据。

**Q：为什么满科技下配比会出现小数？**
A：各建筑吃到的加成不同（只有部分建筑能接水源/筒仓，研究加成也各不相同），有效周期不再成简单整数比。按小数向上取整建造即可，多余的上游产能可以关停部分建筑或外销。

**Q：水源（输水道）到底给多少？**
A：不是 +50%，而是把**基础生产提升到 150%**，且是乘法。所以它同时放大了筒仓、研究、专家等所有加成，是收益最高的一环，优先给「能接水源且数量最多」的上游农场。

**Q：煤要单独算吗？**
A：要。燃煤建筑的煤耗固定为 0.5 吨/分，与周期无关。建议单独规划煤产区（煤矿 0:30 = 2 吨/分），一条贸易线覆盖整座岛。
